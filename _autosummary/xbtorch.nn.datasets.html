xbtorch.nn.datasets

Utilities for preparing and loading character-level name datasets for RNN classification tasks.

This module provides functions to read text files, convert Unicode names to ASCII, encode names as tensors, and split datasets into PyTorch DataLoaders. It also includes training and testing loops for RNN models.

Functions

  • findFiles() : List all files matching a path pattern.

  • unicodeToAscii() : Convert Unicode string to ASCII given a vocabulary.

  • read_lines() : Read lines from a file and convert to ASCII.

  • name_to_tensor() : Encode a name as a tensor of one-hot vectors.

  • get_dataloaders() : Split a dataset into train/test DataLoaders.

  • train_rnn() : Train an RNN model on a given dataset.

  • test_rnn() : Test an RNN model and return predictions and labels.

  • get_names() : Fetch, preprocess, and return the names dataset.

  • NamesDataset : PyTorch Dataset class for names data.
