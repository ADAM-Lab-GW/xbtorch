xbtorch.nn.models

Predefined neural network architectures for use with XBTorch.

This module provides implementations of standard models such as LeNet-5, VGG, and RNN/LSTM-based models suitable for image classification and sequential data tasks.

Classes

  • LeNet5 : Classic CNN for small images (e.g., MNIST).

  • VGG : Deep CNN for image classification tasks (VGG-like).

  • RNN : Simple RNN model with linear output layer.

  • SimpleLSTM : LSTM model with linear output for time-series tasks.

class xbtorch.nn.models.LeNet5[source]

Bases: Module

Classic LeNet-5 CNN architecture for grayscale image classification.

Architecture:

  • 32C5: Conv2d(1, 32, 5x5), ReLU

  • MP2: MaxPool2d(2x2)

  • 64C5: Conv2d(32, 64, 5x5), ReLU

  • MP2: MaxPool2d(2x2)

  • Flatten

  • 512FC: Linear(1024->512), ReLU

  • 10SSE: Linear(512->10)
